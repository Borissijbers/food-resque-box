❓ Veelgestelde vragen

Heb je een vraag over de Food Rescue Box? Misschien staat het antwoord hieronder!

Een Food Rescue Box is een slimme box waarin voedsel dat anders misschien wordt weggegooid, kan worden verzameld en opgehaald.

We willen voedselverspilling verminderen en ervoor zorgen dat voedsel dat nog goed is, bij mensen terechtkomt die het kunnen gebruiken.

Op de homepagina kun je een beschikbare box kiezen. Klik daarna op "Reserveer deze box" en vul je naam en e-mailadres in.

Nadat je een box hebt gereserveerd, krijg je een viercijferige toegangscode. Met deze code kun je de Food Rescue Box openen.

De micro:bit controleert de toegangscode. Als de juiste code wordt ingevoerd, kan de servo de box openen.

SDG 2 staat voor Geen Honger. Ons project probeert voedselverspilling te verminderen en voedsel beschikbaar te maken voor mensen die het kunnen gebruiken.
