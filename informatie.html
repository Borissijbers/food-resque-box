Meer informatie

Ontdek waarom wij de Food Rescue Box hebben bedacht en hoe ons project helpt tegen voedselverspilling.

🍎 Het probleem

Elke dag wordt er voedsel weggegooid terwijl het nog goed genoeg is om te eten. Dit gebeurt bijvoorbeeld bij supermarkten, restaurants en bakkerijen.

Tegelijkertijd zijn er mensen die moeite hebben om voldoende of gezond voedsel te krijgen.

Wij willen deze twee problemen met elkaar verbinden: voedsel dat overblijft een tweede kans geven.

🌱 SDG 2 – Geen honger

Ons project sluit aan bij Sustainable Development Goal 2: Geen honger.

SDG 2 heeft als doel om honger te beëindigen, voedselzekerheid te verbeteren en duurzame landbouw te stimuleren.

Met onze Food Rescue Box willen we op kleine schaal bijdragen aan dit doel door voedsel dat anders verloren zou gaan beschikbaar te maken.

📦 Hoe werkt de Food Rescue Box?

1. 🛒 Een winkel heeft voedsel over

Een supermarkt, restaurant of bakker heeft aan het einde van de dag voedsel dat niet verkocht is.

2. 📦 Het voedsel gaat in de box

Het overgebleven voedsel wordt in een Food Rescue Box geplaatst.

3. 📱 Een gebruiker reserveert een box

Via onze website kan een gebruiker bekijken welke boxen beschikbaar zijn en een box reserveren.

4. 🔢 De gebruiker krijgt een code

Na het reserveren krijgt de gebruiker een persoonlijke 4-cijferige code.

5. 🔓 De box wordt geopend

Bij de Food Rescue Box voert de gebruiker de code in op het toetsenbord.

6. 🤖 De micro:bit controleert de code

De micro:bit controleert of de ingevoerde code overeenkomt met de juiste code.

Is de code correct? Dan stuurt de micro:bit een signaal naar een servo. De servo ontgrendelt de box.

🤖 Welke technologie gebruiken we?

Voor ons prototype gebruiken we een micro:bit.

De micro:bit is het brein van de Food Rescue Box. Hij controleert de ingevoerde code en bestuurt het slot van de box.

We gebruiken daarnaast een keypad om de code in te voeren en een servo om het slot fysiek te openen en weer te sluiten.

❤️ Ons doel

Met de Food Rescue Box willen we laten zien dat technologie kan helpen bij maatschappelijke problemen.

Ons doel is om voedselverspilling te verminderen en tegelijkertijd voedsel toegankelijker te maken voor mensen die het nodig hebben.
